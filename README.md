# Дежурство в «Минутке» — мониторинг и логирование на практике

Практический тренажёр для системных аналитиков школы AMP: неделя дежурства в сервисе доставки «Минутка». В понедельник оплата полчаса не проходила у каждого седьмого клиента, а команда узнала об этом из соцсетей. За неделю вы разбираетесь, что видеть, что искать и когда будить людей.

Внутри — интерактивы, которые можно потрогать: поиск по логам в стиле Kibana, графики и дашборд в стиле Grafana, конструктор запроса метрик, водопад трассы, редактор алерта с бюджетом ошибок. После каждой проверки — ответы с объяснением и разбор на схеме.

Откройте https://andreypol1991.github.io/duty-trainer/ — прогресс хранится в браузере, отчёт для преподавателя — кнопка «Отчёт».
